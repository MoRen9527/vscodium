# VSCodium Registry Layer

## 作用

本目录承接 `VscodiumBusinessStrategyRegistry`、`VscodiumProductRegistry` 和 `VscodiumCodeRegistry` 的工作型资料。

## 真源优先级

1. `../../AGENTS.md`
2. `../../README.md`
3. `../../product.json`
4. 本目录中的登记文档

## 当前文件

- `business-state.md`：vscodium 的商业定位、默认职责与边界
- `product-state.md`：vscodium 的产品状态、模块职责与依赖
- `code-state.md`：vscodium 的代码结构、健康状态与风险

## 更新规则

- 只有在用户明确要求“记录”或“更新”时才修改本目录。
- 对 upstream 与本地定制必须分开记录。
